# 测试范围与已知问题

在一台国行 Redmi K30 Pro 上完成安装和日常使用验证，未覆盖其他地区和所有功能。

## 已观察到

- Android 16 可正常启动、完成设置、进入桌面。
- Wi-Fi 连接、SIM 语音/数据注册、指纹认证与相机服务检查通过。
  注册状态不等于通话音质和长期网络稳定性测试。
- 前摄校准后曾不升起，一次正常重启后恢复升降。
- 基础 SukiSU Root 实机可用，日常使用暂未发现其他明显问题。
- SELinux Enforcing；顶部指示灯已观察到充电时黄色/绿色常亮。

## 待确认或需要留意

- 前摄首次校准后的问题没有源码修复，不能称为永久修复。
- 顶部指示灯曾暂时完全不亮，之后恢复充电常亮；原因未定位，
  通知呼吸/闪烁行为尚未专门确认。
- NFC、蓝牙配对、GPS、VoLTE/VoWiFi、待机耗电和长期稳定性未完整测试。
- POCO F2 Pro 和其他地区变体未独立实测。
- 不保证 Play Integrity、支付/银行、DRM 或游戏环境检查结果。
